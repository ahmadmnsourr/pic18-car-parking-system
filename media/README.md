# Proteus simulation demonstration

- [`parking-simulation-demo.mp4`](parking-simulation-demo.mp4) — ~29-second silent screen recording, focused on the complete Proteus schematic. It shows the system running, vehicle input interactions, timer and final parking fee.
- [`parking-demo-preview.gif`](parking-demo-preview.gif) — short animated preview displayed directly in the repository README. Click it there to open the MP4.

The cropped recording excludes OBS, the taskbar and unused desktop space, while preserving all microcontroller, sensor and display components. The original source recording was provided by the project developer.

For reproducible interaction steps, see [`../docs/SIMULATION_GUIDE.md`](../docs/SIMULATION_GUIDE.md).
